# Security Policy

This repository is educational. Do not use the labs against systems without authorization.

## Reporting a problem in the notes

Please open an issue when you find:

- a command that can cause unintended system changes;
- an outdated security recommendation;
- an unsafe default presented as a production recommendation;
- a broken lab;
- a citation that no longer points to the intended primary source.

For actual security vulnerabilities in external software discussed here, report them to the affected project rather than treating this repository as the vendor's security channel.
